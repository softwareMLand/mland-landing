# MLand Software - Landing Page

Landing page de MLand Software para atraer clientes de negocios locales.

## Despliegue en Cloudflare Pages

1. Conecta este repositorio en Cloudflare Pages.
2. Framework preset: **None** (o Static HTML).
3. Build command: dejar vacío.
4. Output directory: `/` (raíz).
5. Deploy.

## Importante antes de publicar

- Reemplaza el número de WhatsApp en `index.html` (busca `593XXXXXXXXX`).
- Ajusta los precios de los paquetes (busca `$XXX`).
- Si tienes dominio propio, configúralo en Cloudflare Pages.

## Estructura

- `index.html` → Página principal
- `css/style.css` → Estilos
- `js/main.js` → Menú móvil

Hecho para ser rápido, claro y orientado a conversión.
